01 — Systems

What I build at Codet.ai.

A multi-tenant B2B go-to-market automation platform: agents, the graph they reason over, and the data layer underneath.

Neurosymbolic hypergraph · YugabyteDB

CHHG — a knowledge graph that reasons inside the database

Reasoning runs as SQL functions: an ontology-typed graph, symbolic-then-vector retrieval (type and scope filters, then HNSW), geometric scoring over 1024-d embeddings, causal path enumeration, and hierarchical Bayesian belief propagation with in-database Thompson Sampling bandits.

Governed and explainable: OCL formal contracts and FSM model checking gate every agent action and record proof lineage. Git-on-Graph branching enables counterfactual what-if reasoning; an LLM planner writes query plans that a whitelisted validator checks before execution.
